تطبيق الأسعار السورية شرف — الإصدار 14
=====================================

الإضافات في هذا الإصدار:
- سجل تغييرات تكلفة الشراء وسعر المبيع ونسبة الربح، مع التاريخ.
- حساب قيمة الربح بالليرة تلقائياً لكل مادة.
- تصنيف المواد إلى أقسام وإمكانية تصفية القائمة حسب القسم.
- حاسبة محسّنة تشمل الأقواس والنسب المئوية والجذر والتربيع.
- نسخ احتياطي JSON يشمل المواد والإعدادات وسجل الأسعار.
- استعادة ودمج النسخ الاحتياطية دون حذف المواد الموجودة.
- تصدير جدول المواد بصيغة CSV المتوافقة مع Excel.
- طباعة قائمة الأسعار أو حفظها PDF من نافذة الطباعة في المتصفح.
- مشاركة قائمة الأسعار مباشرة عبر واتساب.
- تحديث لوحة الألوان إلى أزرق داكن.

التحديث مع الحفاظ على البيانات:
1) افتح التطبيق الحالي على الهاتف قبل التحديث، ومن قسم النسخ والتصدير اختر «إنشاء نسخة احتياطية» واحفظ ملف JSON.
2) فك ضغط هذه الحزمة وارفع جميع الملفات إلى جذر مستودع GitHub نفسه، مع استبدال الملفات القديمة.
3) لا تغيّر عنوان GitHub Pages ولا اسم المستودع. انتظر اكتمال النشر.
4) افتح رابط التطبيق نفسه في Chrome. لا تمسح بيانات الموقع أو ذاكرة التطبيق ولا تحذف التطبيق المثبت.
5) قاعدة بيانات المواد IndexedDB ما زالت تستخدم الاسم نفسه DaftarAlAsaarDB ومخزن products نفسه؛ لذلك تبقى المواد الموجودة في نفس عنوان الموقع.
6) إذا لزم الأمر، استخدم «استعادة / دمج نسخة» لاستيراد النسخة الاحتياطية؛ الدمج لا يمسح البيانات الحالية.

أماكن التخزين:
- المواد: IndexedDB (DaftarAlAsaarDB / products).
- الإعدادات: localStorage (daftar_settings).
- سجل الأسعار: localStorage (daftar_price_history_v1).

ملاحظات:
- ملف CSV يفتح في Excel ويمكن استيراده كجدول بيانات.
- PDF يتم إنشاؤه من خيار الطباعة ثم اختيار «حفظ بتنسيق PDF» في نافذة الطباعة.
- سجل تغييرات الأسعار يبدأ من هذا الإصدار؛ لا يمكن استرجاع تغييرات لم تكن مسجلة سابقاً.
- حافظ على ملف النسخة الاحتياطية خارج مستودع GitHub العام.
- الأسعار بالليرة السورية القديمة كما في النسخة السابقة.
