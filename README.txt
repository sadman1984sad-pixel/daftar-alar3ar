تطبيق الأسعار السورية شرف — الإصدار 18
=====================================

أهم تحديثات هذا الإصدار:
- إضافة تبويب «التقويم والحكمة» يعرض التاريخ الميلادي والهجري (تقويم أم القرى) بتوقيت دمشق، مع تنبيه لاحتمال اختلاف يوم الرؤية في سوريا.
- عرض مقولة/فكرة مختارة ومعلومة عامة تتجددان عند كل تشغيل للتطبيق، مع أزرار لعرض محتوى آخر.
- تحسين جلب الأخبار بإضافة محاولات متتابعة عبر أكثر من وسيط RSS، وتجربة نطاق زمني بديل عند فشل موجز اليومين.
- تحديث الأخبار تلقائياً عند فتح تبويب الأخبار، مع الاحتفاظ بآخر الأخبار الناجحة محلياً عند تعذر الاتصال.
- إضافة/توسيع تبويب المباريات اليومية: الدوري الإنجليزي، الإسباني، الألماني، الإيطالي، الفرنسي، كأس ملك إسبانيا، دوري أبطال أوروبا، ودوري الأمم الأوروبية.
- عرض وقت انطلاق كل مباراة بتوقيت سوريا (Asia/Damascus)، لا بتوقيت الهاتف أو ألمانيا.
- عرض حالة المباراة: لم تبدأ بعد، مباشرة الآن مع النتيجة/ساعة اللعب عندما يوفرها المصدر، أو انتهت.
- تحديث جدول المباريات كل دقيقة ما دام تبويب المباريات مفتوحاً.
- اختيار التاريخ حسب التقويم السوري، مع البحث في الأيام المجاورة لضمان عدم فقدان المباريات بسبب اختلاف التاريخ العالمي وتصفية النتائج حسب يوم سوريا.

التحديث مع الحفاظ على البيانات:
1) افتح التطبيق الحالي، ومن «النسخ والتصدير» اختر «إنشاء نسخة احتياطية» واحفظ ملف JSON احتياطياً.
2) فك ضغط هذه الحزمة وارفع جميع الملفات الموجودة فيها إلى جذر مستودع GitHub نفسه، مع استبدال الملفات القديمة.
3) لا تغيّر عنوان GitHub Pages ولا اسم المستودع. انتظر اكتمال النشر.
4) افتح رابط التطبيق نفسه في Chrome، ثم حدّث الصفحة. قد يحتاج تحديث Service Worker إلى إغلاق التطبيق وإعادة فتحه مرة واحدة.
5) لا تمسح بيانات الموقع ولا تحذف التطبيق المثبت. قاعدة بيانات المواد تبقى على نفس اسمها ومخزنها.
6) إذا لزم الأمر، استخدم «استعادة / دمج نسخة» لاستيراد النسخة الاحتياطية؛ الدمج لا يمسح بياناتك الحالية.

ملاحظات مهمة:
- الأخبار تحتاج اتصالاً بالإنترنت، وتعتمد على توفر موجز Google News وخدمات وسيطة عامة؛ تمت إضافة أكثر من مسار ومحاولة بديلة، لكن لا يمكن ضمان استمرار خدمات طرف ثالث المجانية دون انقطاع.
- المباريات والنتائج تأتي من واجهة ESPN العامة. حالة «مباشرة الآن» تتحدث كل دقيقة عند إبقاء تبويب المباريات مفتوحاً، وقد لا تتوفر تغطية لكل مباراة أو بطولة.
- جميع مواعيد المباريات تظهر بتوقيت سوريا (دمشق)، بصرف النظر عن المنطقة الزمنية المضبوطة في الهاتف.
- لا تمسح بيانات الموقع حتى لا تفقد المواد المخزنة محلياً.
