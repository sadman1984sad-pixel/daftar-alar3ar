تطبيق الأسعار السورية شرف — النسخة v7
====================================

المزايا الجديدة:
- سعر الشراء الأساسي يُدخل بالليرة السورية القديمة.
- يحسب التطبيق ما يعادل سعر الشراء بالدولار حسب سعر الصرف المختار.
- نسبة ربح افتراضية 10% لكل مادة، ويمكن تعديلها.
- يحسب سعر المبيع بالليرة والدولار تلقائياً.
- جدول يعرض سعر الشراء، نسبة الربح، وسعر المبيع، مع إبقاء بيانات الجملة والطرد.
- مظهر أزرق مع زر للتبديل بين الوضع الداكن والساطع، ويحفظ الاختيار.
- أوقات الصلاة اليومية لمدينة حمص، تُجلب عبر الإنترنت وتُحدّث دورياً مع حفظ آخر مواقيت ناجحة.

التثبيت والتحديث:
1) فك ضغط الحزمة.
2) ارفع الملفات الموجودة داخلها إلى جذر مستودع GitHub، واستبدل الملفات القديمة عند السؤال.
3) احفظ التغييرات عبر Commit changes وانتظر انتهاء نشر GitHub Pages.
4) افتح رابط الموقع. لا تحذف بيانات الموقع أو التطبيق من Chrome.

البيانات:
- تحفظ المواد في IndexedDB داخل المتصفح على الجهاز.
- تحفظ إعدادات سعر الصرف والمظهر محلياً.
- استخدم "نسخ احتياطي" بشكل دوري لتنزيل ملف JSON.
- لا تمسح بيانات المتصفح أو التطبيق قبل أخذ نسخة احتياطية.

ملاحظات مهمة:
- القيم المعروضة بالليرة السورية القديمة وفق معامل التحويل المستخدم في النسخة السابقة.
- عند ترحيل المواد القديمة، يحتفظ التطبيق بسعر المبيع السابق تقريباً بافتراض هامش ربح 10% لاشتقاق سعر شراء أولي؛ لأن سعر الشراء لم يكن محفوظاً في النسخة السابقة. راجع أسعار الشراء بعد التحديث وعدّلها إن لزم.
- سعر الصرف يجلب من Liraty عند فتح التطبيق ثم دورياً أثناء ظهوره. مصدر السعر لا يوفر سعراً مستقلاً مؤكداً لحمص؛ سعر دمشق مرجع تقريبي.
- أوقات الصلاة تجلب من خدمة AlAdhan لمدينة Homs, Syria وفق طريقة حساب محددة، وقد تختلف بضع دقائق عن التقويم المحلي المعتمد.
- يلزم الاتصال بالإنترنت لتحديث أسعار الصرف وأوقات الصلاة. آخر أوقات صلاة ناجحة تبقى محفوظة عند تعذر الاتصال.
- خذ نسخة احتياطية قبل أي تغيير كبير، ولا تضع ملف النسخة الاحتياطية في مستودع GitHub عام.
