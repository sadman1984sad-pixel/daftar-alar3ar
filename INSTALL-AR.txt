تحديث تطبيق الأسعار السورية شرف — الإصدار v8 من هاتف أندرويد
================================================

1) فك ضغط ملف ZIP على الهاتف.
2) افتح مستودع GitHub في Chrome.
3) اختر Add file ثم Upload files.
4) اختر الملفات الموجودة داخل الحزمة بعد فك الضغط (index.html وmanifest.webmanifest وservice-worker.js والأيقونات والملفات النصية)، وارفعها إلى جذر المستودع لاستبدال النسخ القديمة.
5) تأكد من اختيار Commit directly to the main branch ثم اضغط Commit changes.
6) انتظر انتهاء GitHub Pages من النشر، ثم افتح رابط التطبيق.

إذا كان GitHub Pages مضبوطاً على GitHub Actions ولا يعمل تحديث الملفات تلقائياً، افتح Settings > Pages، واجعل Source = Deploy from a branch، ثم Branch = main وFolder = /(root)، واضغط Save. لا تغيّر ذلك إذا كان مشروعك يعتمد سير عمل نشر مخصصاً إلا بعد التأكد من إعداداته.

مهم جداً:
- لا تحذف بيانات الموقع أو التطبيق من Chrome ولا تمسح التخزين؛ المواد محفوظة محلياً في IndexedDB.
- يفضّل تنزيل نسخة احتياطية JSON من تبويب المشاركة والنسخ قبل التحديث.
- سعر الشراء في النسخة الجديدة يُدخل بالليرة السورية القديمة، ويحوّل إلى الدولار تلقائياً.
- نسبة الربح الافتراضية 10% ويمكن تغييرها لكل مادة.
- أوقات الصلاة لحمص تحتاج اتصالاً بالإنترنت للتحديث.
- إذا ظهرت نسخة قديمة، انتظر انتهاء النشر ثم أغلق صفحة التطبيق وافتحها مجدداً.
