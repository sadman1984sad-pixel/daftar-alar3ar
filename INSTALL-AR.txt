طريقة تحديث تطبيق الأسعار السورية شرف — الإصدار 18

1. خذ نسخة احتياطية من داخل التطبيق: النسخ والتصدير ← إنشاء نسخة احتياطية.
2. افتح مستودع GitHub الخاص بالتطبيق من المتصفح.
3. ارفع كل ملفات الحزمة إلى جذر المستودع واستبدل الملفات القديمة، بما فيها index.html وservice-worker.js وملف manifest.webmanifest والأيقونات.
4. انتظر انتهاء GitHub Pages من النشر.
5. افتح رابط التطبيق المعتاد في Chrome وحدّث الصفحة. إذا بقيت النسخة القديمة، أغلق التطبيق وافتحه مجدداً بعد دقيقة.
6. لا تمسح بيانات الموقع ولا تحذف التطبيق؛ المواد والأسعار محفوظة محلياً.

التحديث الجديد يعرض مواعيد المباريات بتوقيت سوريا، ويبيّن المباراة المباشرة والنتيجة وحالة المباراة، ويحدّث المباريات كل دقيقة عند فتح تبويبها.

يتضمن الإصدار 18 تبويب التقويم والحكمة: التاريخ الهجري والميلادي بتوقيت دمشق، ومقولات ومعلومات عامة متجددة عند كل فتح للتطبيق.
